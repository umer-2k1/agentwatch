## Definition of done

1. `npm run tauri dev` opens the strip with one dot per live Claude Code session.
2. Status matches reality for: working, finished, idle.
3. ✅ **VERIFIED** — `kill` flips the dot to `dead` within one tick, confidence `certain`,
   evidence `pid NNNN is gone`. Covered by `tests/liveness_live.rs`.
4. Killing and restarting an agent is handled (no ghost dots).
5. CPU < 1% with all agents idle.
